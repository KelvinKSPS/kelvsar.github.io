Política de Privacidade

Última atualização: Setembro de 2026

1. Visão geral

Este site é uma página pessoal e informativa, mantida por seu proprietário para fins particulares. Em geral, nenhuma informação pessoal é coletada durante a navegação.

2. Coleta de dados

  • Nenhum dado enviado por formulários: este site não possui formulários de contato, cadastro ou coleta de e-mail.
  • Nenhum rastreamento: não são utilizadas ferramentas de analytics, cookies de publicidade ou scripts de terceiros.
  • Logs de servidor: como em qualquer site hospedado, o provedor de hospedagem pode registrar informações técnicas básicas (como data e IP), para fins de operação e segurança. Esses dados não são utilizados para identificação ou perfilamento.

3. Uso das informações

Como não há coleta de informações pessoais, não há uso de dados para publicidade, marketing, análises ou qualquer outra finalidade.

4. Cookies

Este site não utiliza cookies. Nenhuma preferência é armazenada no navegador do visitante por este site.

5. Compartilhamento

Nenhum dado é compartilhado, vendido ou transferido a terceiros. A única entidade que tem acesso técnico às informações de infraestrutura é o provedor de hospedagem do site, conforme os termos do próprio serviço.

6. Segurança

A comunicação com este site é feita exclusivamente via HTTPS. As páginas são estáticas e o site não processa nem armazena dados enviados por visitantes.

7. Links para outros sites

Este site pode conter links para páginas externas. A presente política se aplica apenas a este site; recomenda-se revisar as políticas dos sites visitados.

8. Alterações

Esta política pode ser atualizada a qualquer momento. Alterações serão refletidas nesta página com a data de atualização indicada no topo.

9. Contato

Dúvidas sobre esta política podem ser encaminhadas ao proprietário do site.
